# ADR 008 — No-Code Playbook and Spreadsheet

> 🇺🇸 EN | 🇧🇷 [PT-BR](008-playbook-and-spreadsheet.pt-BR.md) · Status: Accepted (Gate 2, 2026-11-19) · Date: 2026-11-19

## Context
The job posting asks for processes that other people can follow without requiring coding (RF-10).

## Decision
- **`playbook/README.md`** (English): step-by-step workflow to run in Claude or ChatGPT, using the exact same prompts as the code, the human review checklist, and compliance rules in plain language.
- **`playbook/auction-math.xlsx`:** generated by `scripts/build_playbook.py` with openpyxl, containing **real formulas** (CPL, max CPC, and conditional-formatting traffic light) and one tab per demo county.
- Playbook prompts are read from the same prompts module used by the code, and a test fails if the two diverge.

## Deviations from Standard
Deliverable outside the Master Standard, motivated by the job posting.

## Consequences
- Positive: proves "documents, spreadsheets" and "processes others can use."
- Plan impact: Phase 9.

## Review Criterion
PRD cut #2: if timeline tightens, drop the spreadsheet and keep the math only in Markdown.
