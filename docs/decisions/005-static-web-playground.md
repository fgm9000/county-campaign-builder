# ADR 005 — Static Web Playground

> 🇺🇸 EN | 🇧🇷 [PT-BR](005-static-web-playground.pt-BR.md) · Status: Accepted (Gate 2, 2026-11-19) · Date: 2026-11-19

## Context
Evaluators are likely from marketing or operations (PRD, Section 2) and need to see the traffic light and the corrected number within 30 seconds (Section 5).

## Decision
Static page on GitHub Pages, reusing the `briefing-scout` structure:
- **English as default**, with PT as second language;
- first screen: the **3-county table with the traffic light** and the **corrected number**, above the fold;
- below, one county expanded at a time: sourced facts, qualification questions, ads with visible character counts, LP, SMS, emails, and the human review list;
- live tab: FIPS, vertical, bid, and CPC/conversion ranges, with access code;
- links to the playbook and spreadsheet;
- same safeguards: strict CSP, text inserted only via `textContent`, `examples.json` generated by the graph with a drift test.

## Deviations from Standard
None.

## Consequences
- Plan impact: Phase 9.

## Review Criterion
If in the 30-second test a reader cannot find the traffic light, move the table above the intro copy.
